AI app builders and agents

Self-hosted alternatives to OpenAI GPTs and Assistants, Relevance AI, Stack AI and LangChain hosted tools.

What people say

  • build an AI agent without code
  • prototype a RAG app
  • chain LLM calls into a workflow
  • run AI agents on my own data
  • a private GPTs builder for my team

Why people self-host it

People leave OpenAI GPTs and Assistants, Relevance AI, Stack AI, LangChain hosted tools for it. Why, strongest first: privacy, cost, control.

Does it suit a machine of your own?

Good fit the builder is a web app for the team, and what it publishes is an API or webhook

Questions that decide it

  • what should the agent or app do, and for whom?
  • which models: hosted APIs or local?

How to publish it

Usually
the builder on org; each published flow's API on api-key; webhooks from other services on none
When the data is private or sensitive
org and api-key only

Who sees what inside it

agents act with the credentials they are given: give each one only the keys and tools it needs

The machine

modest; the model runs elsewhere unless it is local

For builders

a fast way to prototype an AI feature or product and let early users try it through an API
